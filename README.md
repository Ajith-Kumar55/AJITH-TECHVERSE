## 6. How to Run Locally

You can run **AJITH-TECHVERSE** locally without installing heavy build tools:

### Option A: Direct Browser Execution
Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Option B: Local HTTP Server (Recommended)
Running through an HTTP server ensures Three.js WebGL textures and API fetches operate with standard security headers:

```bash
# Using Python (standard on Windows/macOS/Linux)
cd c:\AJITH-TECHVERSE
python -m http.server 8080
```
Open your browser and navigate to: `http://localhost:8080`

```bash
# Using Node.js (npx)
cd c:\AJITH-TECHVERSE
npx serve .
```

## 7. Cloud Deployment Guide

### Deploying to GitHub Pages
1. Initialize git and commit your files:
   ```bash
   cd c:\AJITH-TECHVERSE
   git init
   git add .
   git commit -m "feat: initial release of AJITH-TECHVERSE Nexus 2040"
   ```
2. Create a repository named `AJITH-TECHVERSE` on your GitHub account (`https://github.com/Ajith-Kumar55`).
3. Link and push your repository:
   ```bash
   git remote add origin https://github.com/Ajith-Kumar55/AJITH-TECHVERSE.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings** ➔ **Pages** ➔ under **Branch**, choose `main` and `/ (root)` ➔ Click **Save**.
5. Your website will be live at: `https://ajith-kumar55.github.io/AJITH-TECHVERSE/`

### Deploying to Vercel
1. Install Vercel CLI (`npm install -g vercel`) or sign in at [vercel.com](https://vercel.com).
2. Run `vercel` inside `c:\AJITH-TECHVERSE` or import the GitHub repository directly.
3. The included `vercel.json` automatically configures clean URLs and security headers.

### Deploying to Netlify
1. Drag and drop the `AJITH-TECHVERSE` folder into the [Netlify Drop](https://app.netlify.com/drop) dashboard, or connect your GitHub repository.
2. The included `netlify.toml` handles routing and security headers automatically.
