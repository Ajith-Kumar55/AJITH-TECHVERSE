## 6. How to Run Locally

You can run AJITH-TECHVERSE locally without installing heavy build tools.

### Option A: Direct Browser Execution

Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Mozilla Firefox or Safari.

### Option B: Local HTTP Server (Recommended)

Using Python:

```bash
cd C:\AJITH-TECHVERSE
python -m http.server 8080
```

Open your browser:

`http://localhost:8080`

Using Node.js:

```bash
cd C:\AJITH-TECHVERSE
npx serve .
```

## 7. Cloud Deployment Guide

### Deploying to Netlify (Current Live Deployment)

**Live Website:** https://ajith-techverse-jgbr.netlify.app/

1. Sign in to [Netlify](https://www.netlify.com/).
2. Connect your GitHub account.
3. Import the `AJITH-TECHVERSE` repository.
4. Configure the publishing directory as the project root.
5. Deploy the website.
6. Netlify automatically deploys new changes whenever commits are pushed to the `main` branch.

### Deploying to GitHub Pages

1. Navigate to GitHub repository Settings → Pages.
2. Select the `main` branch.
3. Select `/ (root)` as the publishing directory.
4. Click Save.

### Deploying to Vercel

1. Sign in to [Vercel](https://vercel.com/).
2. Import the GitHub repository.
3. Configure project settings.
4. Deploy the website.

The included `vercel.json` provides deployment configuration.
